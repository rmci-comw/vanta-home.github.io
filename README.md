# VANTA HOME

**Light Your Space. Live Your Mood.**

Professional static ecommerce storefront concept with **16 demo products**, room-based browsing, lighting collections, support, cart, wishlist, guides, and responsive design.

## Image standard
Each product card uses one standalone product image, centered inside a square frame with `object-fit: contain`. Product photographs are separate from the web UI and do not embed prices, ratings, buttons, navigation, or screenshots.
